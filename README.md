# Cost-Aware LLM Gateway

![tests](https://github.com/Anjalik112/llm-gateway/actions/workflows/tests.yml/badge.svg)

One API in front of several LLM providers: routes each prompt to the cheapest model that is good enough, falls back across providers, caches repeated prompts, enforces a daily budget, and logs tokens, cost and latency for every call.
